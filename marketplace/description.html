Export YouTrack issues to Excel (.xlsx) or CSV in a few clicks. Pick a project, filter its issues the same way you do in the YouTrack issue list, choose the columns, check the preview and download the file.

Filter like in YouTrack

  • Choose a project, then add filters with + or by typing, just like the YouTrack search bar.
  • Each filter becomes a chip such as Assignee is … with a value list that supports multiple values, Unassigned and Me.
  • Typing suggests matching fields and values (for example, fix → State: Fixed) or searches for the text.
  • Filters and columns always match the selected project's own custom fields.

Choose your columns

  • Add any built-in or custom field as a column, reorder by drag and drop or with the keyboard.
  • See the first matching issues in a live preview before you export.

Ready-to-use files

  • Excel (.xlsx): bold, frozen header row, auto filter, real date cells and an export info sheet.
  • CSV: UTF-8 with BOM so Excel shows all characters correctly, with a choice of ; or , as the separator and protection against CSV injection.
  • Files are named after the project and the date, for example Website 2026-11-23.xlsx.

Native and private

  • Built with YouTrack's own UI components; follows the light or dark theme you selected in YouTrack.
  • Available in English and Turkish, following the YouTrack user's language.
  • Runs entirely in your browser with the signed-in user's permissions. It only reads issues (READ_ISSUE), never changes data, and sends nothing outside your YouTrack instance.
